The protocol is the execution plan for the PRD's first estimation phase; the PRD says what to build, the protocol says how to prove it can work.

## Notes

- Both documents are personal portfolio samples written as proposals. They are not company-approved plans and contain no client or participant information.
- The protocol has not been submitted to any ethics committee. Expected reliability values in it are design assumptions, not measured results.
- Thresholds and rule parameters are intentionally left unspecified.
