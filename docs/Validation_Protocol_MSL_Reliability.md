## 1. 背景與理由 / Background & Rationale

### 1.1 問題

MSL 已累積大量檢測資料。現行報告呈現單次結果，
客戶（教練、物理治療師、運動員）普遍以跨時間比較的方式使用這些數字：
「這次比上次好嗎？」

**但目前無法回答這個問題。** 因為缺少一個前提：

> 兩次檢測之間的數值差異，有多少來自真實改變，有多少來自量測本身的誤差？

沒有這個基準，任何「進步了 X%」的陳述都無法區分訊號與雜訊。

### 1.2 為何這是產品的必要條件而非學術加分

`MSL-PRD-REPORT-2026-001` 將縱向追蹤列為 P0 功能，其核心判定邏輯
（FR-1.3）依賴兩個參數：**典型誤差（TE）** 與 **最小有意義變化（SWC）**。

這兩個參數無法從文獻直接套用，原因有三：

1. 各實驗室的動作指令、暖身流程、設備取樣率不同，TE 不可移植
2. SWC 依族群的組間變異而定，競技運動員與一般健身族群不同
3. MSL 部分指標（如 Dynamic Stability 之 COP 時窗定義）為實驗室自訂，無對應文獻值

**因此本研究是產品開發的前置條件，不是後續的學術補強。**

### 1.3 已知文獻位置

測力板 CMJ 之跳躍高度再測信度在文獻中普遍報告為 ICC > 0.90。
COP 相關之姿勢控制指標信度較低且變異較大。
本研究之預期 ICC 分層（附錄 B）即依此分布設定，並於分析後與文獻對照。

> ⚠️ 本節僅陳述文獻的**大致分布位置**以支持設計假設，
> 不引用具體數值。正式送審版本須補上完整文獻清單與引用。

## 2. 目的與假設 / Objectives & Hypotheses

### 2.1 主要目的（Primary Objective）

量化 MSL 各檢測指標之**再測信度**，並據此推導：

| 參數 | 用途 |
|---|---|
| ICC(2,1) | 相對信度：個體在群體中的排序是否穩定 |
| TE（典型誤差） | 絕對信度：單次量測的預期誤差量 |
| MDC₉₅ | 判定「有改變」所需的最小差值 |
| SWC | 判定「改變有實務意義」的門檻 |

### 2.2 次要目的（Secondary Objectives）

- **SO-1** 檢驗各指標是否存在系統性偏誤（學習效應／疲勞效應）
- **SO-2** 比較左右側指標之信度是否對稱
- **SO-3** 依族群分層（競技／一般健身／復健）分別估計 TE 與 SWC
- **SO-4** 判定各指標之訊號雜訊比（TE vs SWC），決定其是否適用於縱向追蹤

### 2.3 假設（Hypotheses）

| # | 假設 | 方向 |
|---|---|---|
| H-1 | Jump Height、RFD、Eccentric Deceleration 之 ICC ≥ 0.90 | 高信度 |
| H-2 | Dynamic Stability、Balance（Sway Velocity）之 ICC 介於 0.75–0.90 | 中高信度 |
| H-3 | 三次試跳間不存在顯著系統性偏誤（p > 0.05） | 虛無假設 |
| H-4 | 僅 ICC 極高（> 0.96）之指標能滿足 TE < SWC；預期多數指標落在邊際或不適用範圍（推導見下） | SO-4 |

> **H-4 是最關鍵的假設，也是最容易被高估的一項。**
> 因 TE ≈ SEM = SD × √(1 − ICC)，而 SWC = 0.2 × SD，
> 條件 TE < SWC 等同於要求 √(1 − ICC) < 0.2，即 **ICC > 0.96**。
> 在預期 ICC 為 0.75–0.90 的情況下（附錄 B），TE / SWC 約為 1.6–2.5，
> 因此預期僅有少數指標、甚至沒有指標能滿足 TE < SWC。
>
> 若某指標的 TE 大於 SWC，以單次檢測前後差值判定個人層級變化時，
> 無法區分具實務意義的變化與量測雜訊；群體層級的平均變化仍可偵測，
> 個人層級亦可借多次量測平均降低雜訊。
> 此類指標將依 PRD FR-1.4 之規定，**不提供變化判定，僅呈現原始值**。

## 3. 研究設計 / Study Design

### 3.1 設計類型

**前瞻性、單中心、重複量測信度研究**
（Prospective, single-centre, repeated-measures reliability study）

採兩階段設計：

| 階段 | 類型 | 資料來源 | 目的 |
|---|---|---|---|
| **Phase A** | 回溯性次級分析 | 現有檢測資料庫中，14 天內重複檢測之個案 | 取得初步 TE 估計，用於 Phase B 之設計驗證與族群分層依據 |
| **Phase B** | 前瞻性重複量測 | 新招募受試者 | 取得標準化條件下之正式 TE、ICC、MDC、SWC |

**為何需要 Phase A：** 現有資料庫的重複檢測未控制間隔與介入，
不適合直接作為信度估計。但它可以低成本地回答兩個設計問題：
各指標的變異量級大致落在哪裡、族群分層的邊界該畫在哪裡。
**Phase A 的結果不進入最終參數，僅用於設計決策。**

### 3.2 Phase B 時序

```
Day 0    familiarisation（熟悉場次，資料不納入分析）
         ↓ 48–72 小時
Day 2–3  Session 1：3 次有效試跳 / 每個測項
         ↓ 48–72 小時
Day 4–6  Session 2：3 次有效試跳 / 每個測項
```

**間隔設定 48–72 小時的理由：**

- 下限 48h：避免前次檢測之神經肌肉疲勞殘留
- 上限 72h：避免期間發生真實的生理適應
- 期間限制：受試者須維持日常活動，**不得進行高強度下肢訓練**（以訓練日誌記錄）

**Familiarisation 場次的必要性：** CMJ 與單腳動作存在學習效應。
若不設熟悉場次，Session 1 與 Session 2 的差異將混入學習成分，
使 TE 被高估。此場次資料**不納入分析**。

## 4. 受試者 / Participants

### 4.1 納入條件（Inclusion Criteria）

- 年齡 18–45 歲
- 近 6 個月內規律運動（每週 ≥ 2 次）
- 能在無輔助下完成雙腳與單腳跳躍

### 4.2 排除條件（Exclusion Criteria）

- 近 6 個月內下肢手術或骨折（S-3 復健後期層除外，該層以「已完成復健、恢復運動 ≥ 3 個月」為準）
- 檢測當下有下肢疼痛或活動受限
- 前庭系統疾病或平衡功能障礙診斷
- 檢測前 24 小時內飲酒或使用影響神經肌肉功能之藥物
- 懷孕

### 4.3 族群分層（Stratification）

| 層 | 定義 | 目標人數 |
|---|---|---|
| S-1 競技 | 現役校隊／職業隊，每週訓練 ≥ 8 小時 | 20 |
| S-2 一般健身 | 規律運動但非競技 | 20 |
| S-3 復健後期 | 下肢傷後已完成復健、恢復運動 ≥ 3 個月 | 20 |

**分層的理由：** SWC = 0.2 × 組間標準差。
組間變異在三個族群間不同，混合估計會使 SWC 對任一族群皆失準。

### 4.4 招募與退出

- 招募來源：MSL 既有客戶（自願參與）與擬合作單位之公告
- 退出標準：兩次 session 之間發生傷害、或未依規定限制訓練者
- 預期流失率 15%，招募目標上修至 **n = 72**（每層 24 人；60 ÷ 0.85 = 70.6，進位為 71，再取三層可均分之 72）

> 期中檢視以實際完成數為準：若 Phase B 前 40 人之實際流失率高於 15%，
> 於期中追加招募至完成 60 筆有效資料為止。
> **不以估計值取代實際完成數。**

## 5. 樣本數估算 / Sample Size Estimation

### 5.1 方法

信度研究之樣本數依 **ICC 信賴區間精度** 估計（Bonett, 2002）：

```
        8 × z²_(α/2) × (1 − ρ)² × [1 + (k − 1)ρ]²
n  =   ──────────────────────────────────────────  + 1
                    k(k − 1) × w²
```

| 符號 | 意義 | 本研究設定 |
|---|---|---|
| ρ | 預期 ICC | 依指標分層 0.80 / 0.85 / 0.90 |
| k | 每人重複次數 | 3 |
| w | 目標 95% CI 寬度 | 0.10 |
| z | 常態分位數 | 1.96（α = 0.05） |

### 5.2 計算

**z² = 1.96² = 3.8416**

以 ρ = 0.90、k = 3、w = 0.10 為例：

```
(1 − ρ)²          = (0.10)²        = 0.0100
[1 + (k−1)ρ]²     = (1 + 2×0.90)²  = (2.80)²  = 7.8400
k(k − 1)          = 3 × 2          = 6
w²                = 0.10²          = 0.0100

n = (8 × 3.8416 × 0.0100 × 7.8400) / (6 × 0.0100) + 1
  = 2.40945 / 0.06 + 1
  = 40.16 + 1
  = 41.16  →  42
```

### 5.3 各情境所需樣本數

| 預期 ICC | k = 2 | **k = 3** |
|---|---|---|
| 0.90 | 57 | **42** |
| 0.85 | 120 | **86** |
| 0.80 | 201 | **140** |

**採用 k = 3（每測項 3 次有效試跳）** — 由 k=2 提升至 k=3 可使所需樣本數下降約 26–30%，
而增加的受試者負擔有限（單次 session 內完成）。

### 5.4 最終決定與其代價

**採用 n = 60（每層 20 人），k = 3。**

此決定**未滿足** ICC 0.85 與 0.80 情境下 w = 0.10 的要求。
其實際精度如下：

| 預期 ICC | n = 60, k = 3 之 95% CI 寬度 |
|---|---|
| 0.90 | 0.083（±0.041） |
| 0.85 | 0.119（±0.060） |
| 0.80 | 0.153（±0.077） |

**接受此代價的理由：**

1. 高信度指標（H-1 群組）為縱向追蹤的主要載體，其精度已足（±0.041）
2. 中信度指標（H-2 群組）的 ±0.06 精度足以支持「是否 > 0.75」之判定，
   而該判定正是 SO-4 所需
3. 達到 ICC 0.80 情境之 w = 0.10 需 n = 140，以單中心與現有人力不可行

> **此節刻意保留未達標的部分並說明取捨。**
> 一份宣稱所有情境皆滿足的樣本數估算，通常是把參數往回湊出來的。

### 5.5 SWC 估計所需之樣本

SWC = 0.2 × SD_between。SD 的估計精度隨 n 提升；
n = 20/層 時，SD 的 95% CI 約為點估計的 ±32%
（依 χ² 分布，df = 19）。

**因應：** SWC 於首版標示為**暫定值**，於累積 n ≥ 50/層 後重新估計並更新版本
（對應 PRD FR-1.4「累積足夠之標準化重複檢測資料（每層 n ≥ 50）後重新估計，版本化留存」）。

## 6. 檢測流程 / Test Procedure

### 6.1 標準化控制項

| 項目 | 規定 | 理由 |
|---|---|---|
| 檢測時段 | 兩次 session 相差 ≤ 2 小時（同時段） | 控制日內變異 |
| 暖身 | 統一流程，固定時長 | 暖身程度影響 RFD 與跳躍高度 |
| 鞋具 | 兩次相同 | 鞋底剛性影響著地峰值 |
| 口令 | 逐字稿，同一施測者 | 「盡全力跳高」與「跳快一點」導出不同策略 |
| 手部位置 | 雙手插腰 | 排除擺臂貢獻 |
| 施測者 | 全程同一人 | 排除施測者間變異 |
| 回饋 | 不提供成績回饋 | 避免受試者追逐前次數值 |

> **「不提供成績回饋」是容易被忽略但影響最大的一條。**
> 若受試者知道上次跳了幾公分，Session 2 將混入動機效應，
> 該效應會被錯誤地計入 TE。

### 6.2 測項與試跳數

| 測項 | 有效試跳 | 試跳間休息 |
|---|---|---|
| CMJ（雙腳） | 3 | 30 s |
| SCMJ（左） | 3 | 30 s |
| SCMJ（右） | 3 | 30 s |
| 閉眼單腳站（左） | 1 × 30 s | 60 s |
| 閉眼單腳站（右） | 1 × 30 s | 60 s |

**有效試跳定義：** 無額外預備動作、無明顯屈膝落地失衡、
未觸及支撐物、完整完成 30 s（平衡測項）。
不符者當場重測，最多重測 2 次。

### 6.3 設備

- 測力板：MSL 現行設備（型號與取樣率於正式版補列）
- 校正：每個 session 開始前執行零點校正並記錄
- 環境：室溫 22–26 °C，記錄實際值

## 8. 統計分析計畫 / Statistical Analysis Plan

### 8.1 分析前處理

1. **遺漏值**：不進行插補。任一指標遺漏者，該指標分析中排除，其餘保留（available-case analysis）
2. **離群值**：定義為距中位數 > 3 倍四分位距者。**不刪除**，但執行敏感度分析（含／不含之結果並列）
3. **異質變異檢查**：繪製「差值 vs 平均值」圖。若殘差隨數值增大而擴大，該指標取自然對數後分析，TE 以 **CV%** 表示

### 8.2 系統性偏誤（SO-1）

- 三次試跳之間：重複量測 ANOVA，事後配對比較採 Bonferroni 校正
- 兩個 session 之間：配對 t 檢定（常態）或 Wilcoxon 符號等級檢定（非常態）
- 常態性以 Shapiro–Wilk 檢定併視覺化判定

**若存在顯著系統性偏誤**，則於報告中揭露，並將該偏誤量從 TE 估計中分離陳述，
不得混入 TE 使其被稀釋。

### 8.3 相對信度：ICC

**模型：ICC(2,1)** — 二因子隨機效果、絕對一致性、單次量測
（two-way random effects, absolute agreement, single measurement）

**選此模型的理由：** 本研究關心的是「單一次檢測的結果可不可信」，
而非「三次平均後可不可信」。客戶實際收到的報告基於單次檢測，
因此 single measurement 為正確選擇。使用 ICC(2,k) 會系統性高估實務信度。

**判讀門檻**（Koo & Li, 2016）：

| ICC | 判讀 |
|---|---|
| < 0.50 | 差 |
| 0.50 – 0.75 | 中等 |
| 0.75 – 0.90 | 良好 |
| > 0.90 | 優秀 |

報告 ICC 點估計與 95% CI。**判定依 CI 下界，不依點估計。**

### 8.4 絕對信度：TE、SEM、MDC

```
TE   = SD_diff / √2                    典型誤差
SEM  = SD_pooled × √(1 − ICC)          量測標準誤
MDC₉₅ = 1.96 × √2 × SEM = 2.77 × SEM   最小可偵測變化（95%）
```

TE 與 SEM 在理論上一致，**兩者皆報告並比對**；
若差異顯著，代表 ICC 估計或變異結構存在問題，須回頭檢查。

異質變異之指標改以 **CV% = (TE_log 之反對數 − 1) × 100** 表示。

### 8.5 實務意義門檻：SWC

```
SWC = 0.2 × SD_between-subject
```

依 §4.3 之三層分別估計。

### 8.6 訊號雜訊判定（SO-4）— 本計畫的決策終點

| 條件 | 判定 | 產品處置（對應 PRD FR-1.3／FR-1.4） |
|---|---|---|
| TE / SWC < 0.8（約 ICC > 0.97） | **良好** | 提供完整變化判定（灰／黃／綠紅三態） |
| TE / SWC 介於 0.8–1.2（約 ICC 0.94–0.97） | **邊際** | 提供變化判定，但門檻改用 MDC₉₅（較嚴格） |
| TE / SWC > 1.2（約 ICC < 0.94） | **不適用** | **不提供變化判定，僅呈現原始值** |

> ICC 換算假設 TE ≈ SEM 且 SWC = 0.2 × SD；比值恰為 0.8 與 1.2 者歸入「邊際」。

### 8.7 一致性視覺化

Bland–Altman 圖：
```
偏誤（bias）= mean(Session2 − Session1)
一致性界限（LoA）= bias ± 1.96 × SD_diff
```
報告 bias 與 LoA 之 95% CI。

### 8.8 軟體與可重現性

- 分析以腳本執行，腳本與資料版本一併留存
- 分析計畫於資料鎖定（data lock）**之前**定稿，鎖定後不得修改
- 任何計畫外分析明確標示為 **post-hoc / exploratory**

## 9. 允收標準 / Acceptance Criteria

本研究不設「成功／失敗」的二元判準——信度是被量測的性質，不是被通過的門檻。
但產品導入需要明確的決策規則：

| # | 準則 | 門檻 | 未達成之處置 |
|---|---|---|---|
| AC-1 | 主要指標之 ICC 95% CI 下界 | ≥ 0.75 | 該指標降為「僅呈現原始值」 |
| AC-2 | 滿足 TE < SWC 之指標數（預期為少數，見 §2.3 推導） | ≥ 1 項 | 個人層級縱向判定延後；改以 MDC₉₅ 提示大幅變化或僅作群體層級分析，並重新檢視標準化流程 |
| AC-3 | 三次試跳間無顯著系統性偏誤 | p > 0.05 | 修訂試跳數或暖身流程後重測 |
| AC-4 | 有效資料完成率 | ≥ 85% | 檢視排除條件與流程可行性 |
| AC-5 | AI 之 ICC 95% CI 下界 | ≥ 0.70 | AI 不納入變化判定，僅作單次橫斷描述 |

> **AC-2 是產品能否上線的關鍵條件。**
> 若沒有任何指標滿足 TE < SWC，PRD 之 M-1 個人層級判定失去基礎——
> 屆時正確的決定是**延後或縮限功能範圍**，而不是降低門檻。

## 附錄 A：統計公式 / Statistical Formulae

**樣本數（Bonett, 2002）**
```
n = 8 z²(1−ρ)²[1+(k−1)ρ]² / [k(k−1)w²] + 1
```

**典型誤差（Hopkins）**
```
TE = SD_diff / √2
```

**量測標準誤**
```
SEM = SD_pooled × √(1 − ICC)
```

**最小可偵測變化（95% 信心）**
```
MDC₉₅ = 1.96 × √2 × SEM = 2.77 × SEM
```

**最小有意義變化**
```
SWC = 0.2 × SD_between-subject
```

**不對稱指數**
```
AI (%) = |Strong − Weak| / (Strong + Weak) × 100
Symmetry % = 100 − AI
```

**Bland–Altman 一致性界限**
```
LoA = bias ± 1.96 × SD_diff
```

**變異係數（異質變異時）**
```
CV% = (antilog(TE_log) − 1) × 100
```
